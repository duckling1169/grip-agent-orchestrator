# Grip API versus app audit

Static audit, 2026-11-18. No daemon, preview, model, or tests were run. Only this report was written. The task's explicit prohibition on running models also precluded delegated model work. Citations use repository-relative paths and source line numbers. Ranges identify the implementation inspected. Findings about absent controls come from the complete API client and component implementations cited below.

Implementation is authoritative. Read guidance: `CLAUDE.md:1-81`; MCP/chats: `DESIGN.md:135-218`; displayed facts: `DESIGN.md:263-282`; app/routes: `DESIGN.md:373-422`; known gaps: `DESIGN.md:498-551`. The design route list omits some implemented routes, including engines and several push operations (`DESIGN.md:402-422`; `src/web/server.ts:224-251`).
