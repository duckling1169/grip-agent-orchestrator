---
name: creative-ideation
description: Generate five independent, mechanically distinct ideas from a creative brief.
---

Read the brief, constraints and assigned lens. Work independently: do not read other ideators' output or banned-idea lists. Honor explicit user restrictions.

Generate five less-typical ideas. For each, give a numeric probability below 0.10, following [Verbalized Sampling](https://github.com/CHATS-lab/verbalized-sampling). These are uncalibrated model guesses, not evidence of rarity; do not discard an idea based on the number. Make the ideas differ in mechanism or user value, not just theme. Use an optional stimulus only if it changes the mechanism.

For each idea, give its name, promise, concrete steps, mechanism, closest known prior art and uncertainty, feasible first version, weakest assumption, and a cheap falsification test. For interactive ideas describe input and feedback. For games include the rounds, decisions and scoring. Return all five; do not build or select a winner.
